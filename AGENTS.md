# Engineering instructions

Keep this project independent of its parent repository. Use synthetic aggregated data only.
Keep forecasting and optimization in services/ml, never in React. Every proposed donor must pass a post-transfer safety calculation. Inventory mutations must be transactional and idempotent. Approval requires a district officer role and an audit record. Preserve separate state training datasets; the aggregator receives weights and sample counts only.
Run pytest, Ruff, frontend typecheck, production build, and browser smoke tests after relevant changes. Document simplifications and distinguish measured results from assumptions. Never commit credentials or generated databases.
